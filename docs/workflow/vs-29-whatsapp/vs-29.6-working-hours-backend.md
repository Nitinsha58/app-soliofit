# VS-29.6 — Boutique Working Hours (backend)

**Program:** [VS-29 overview](./00-overview.md) · **Layer:** Backend (`apps/users`) · **Status:** Pending
**Depends on:** — (additive, independent). Consumed by 29.8.

Add boutique working hours so the WhatsApp Ready message can derive a real `{pickup_window}`.
Additive and **non-breaking** — nullable fields, no behavior change to existing endpoints.

## Scope (in)

1. **Model** — `opening_time` + `closing_time` (`TimeField`, `null=True, blank=True`) on
   `Boutique` (`apps/users/models.py`). One additive migration.
2. **Editable via order-settings** — add both to `BoutiqueSettingsSerializer`
   (`GET/PATCH /api/auth/order-settings/`). Optional on PATCH; validate `opening < closing` when
   both are provided (else a clean 400). Returns `null` when unset.
3. **Read-only on the `me` payload** — expose `opening_time` / `closing_time` on `UserSerializer`
   (sourced from `user.boutique`) so the frontend auth store carries them for send-time pickup-window
   derivation, the same path `business_name` already uses (no extra fetch on the send surfaces).
4. **Tests** — order-settings round-trip incl. the new fields; `opening >= closing` rejected;
   unset → `null`; `me` payload exposes the hours.

## Scope (out)

- No Settings UI (29.8). No template wiring (29.8). No pickup-window string formatting (that is
  derived client-side in 29.8).
- No change to `delivery_buffer_days` / `daily_capacity` behavior.

## Files

- Modified: `apps/users/models.py` (+ migration), `apps/users/serializers.py`
  (`BoutiqueSettingsSerializer` + `UserSerializer`), `apps/users/tests.py`.

## Review (how to verify)

- Migrate in Docker; `makemigrations --check` no drift.
- `PATCH /api/auth/order-settings/ {opening_time, closing_time}` → 200, persists; `GET` returns them;
  `opening >= closing` → 400; `GET /api/auth/me/` includes the hours.
- Full backend suite green.

## Done when

The boutique can store working hours via order-settings, the `me` payload exposes them read-only,
and nothing about existing endpoints changes.
