# VS-28.1 — Tab Shell + Overview Core

**Program:** [VS-28 overview](./00-overview.md) · **Layer:** Frontend (Order Detail drawer) · **Status:** Implemented — in review

> **Frontend Design Gate:** read `07-ux-guidelines.md §0` and run §0.10 before editing this UI.

Establish the tabbed shell (Overview · Work · Money) and build the Overview's command-screen
core. Work/Money/More-Details mount the **existing** sections as interim content so no current
behavior is lost; later slices refine each.

## §0.10 pre-build checklist (Overview) — all "yes"

- Main goal visible in 5s? ✅ due date + outstanding + primary action at the top.
- One dominant action? ✅ the stage-aware primary.
- Rare actions hidden? ✅ in the pushed More Details.
- Related things grouped? ✅ identity / attention / payment snapshot / note as distinct cards.
- Readable without editing? ✅ Overview is read-only; editor lives in Money.
- Colors only for meaning? ✅ green/amber/red/grey by status.
- Status without calculating? ✅ "in N days" / "overdue" / "₹X outstanding" pre-computed.
- Destructive separated? ✅ Danger Zone is in More Details.

## Scope (in)

1. **Tab shell** — `OrderDetailDrawer/index.tsx`: persistent identity strip + `DrawerTabs`
   (Overview · Work · Money) + a pushed **More Details** view. Retire `QuickActions`
   scroll-shortcuts (tabs replace them).
2. **Overview** (`OverviewTab`):
   - Status pill (dropdown) + priority pill (reusing `updateOrderStatus` / `updateOrder`).
   - `AttentionSummaryCard` — due date + urgency, payment state + outstanding (from order fields;
     color = status).
   - `PrimaryAction` — stage-aware (Booked→Start work, Started→Mark Ready, Ready/Partial→Mark
     Delivered, Delivered→none); Delivered confirmed, earlier steps one-tap.
   - `OverviewPaymentCard` — **read-only** snapshot (bill / paid / outstanding / progress from
     `total_amount`, `amount_paid`, `remaining`) + "View plan ›" → Money tab.
   - Order note preview (remarks) + a **More Details** row → pushed screen.
3. **Interim tabs (no regression):** Work = existing `PhotoSection` + `VoiceSection`; Money =
   existing `PaymentSchedule`; More Details = `OrderInfoSection` (payments suppressed) +
   `ActivityFeed` + `DangerZone`.

## Scope (out)

- No backend changes. No rewrite of `OrderHeader.tsx` (kept untouched; new header components used).
