# VS-28.4 — More Details (pushed screen)

**Program:** [VS-28 overview](./00-overview.md) · **Layer:** Frontend · **Status:** Pending

> **Frontend Design Gate:** read `07-ux-guidelines.md §0` and run §0.10 before editing this UI.

Group the secondary/admin content into one focused, pushed **More Details** screen reached from
an Overview row — keeping it off the main path (progressive disclosure, §0.4).

## Scope (in)

- Customer details (name, phone, address) — read-only with edit affordance.
- Order details — delivery date (tap-to-edit), bill (read-only; edited only in Money), status.
- Internal remarks (tap-to-edit).
- Activity (`ActivityFeed`).
- Danger zone (`DangerZone` / delete) — visually separated, bottom.

## Scope (out)

- The bill stays read-only here (VS-27.5 invariant); editing is Money-only.

## Done when

More Details is a single pushed screen grouping customer/order/remarks/activity/danger, with the
destructive action clearly separated; the main Overview stays uncluttered.
