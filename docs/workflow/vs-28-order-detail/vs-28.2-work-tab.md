# VS-28.2 — Work Tab (Work Instructions card)

**Program:** [VS-28 overview](./00-overview.md) · **Layer:** Frontend · **Status:** Implemented — in review

> **Frontend Design Gate:** read `07-ux-guidelines.md §0` and run §0.10 before editing this UI.

Merge garment photos, measurement notes photos, and voice notes into one **"Work Instructions"**
card on the Work tab — the way a tailor thinks ("what do I need to make this order correctly?").

## Scope (in)

- Combine `PhotoSection` (garment + measurement-notes buckets) and `VoiceSection` (record +
  playback) into a single grouped **Work Instructions** card.
- A compact Overview "Work Instructions" preview (counts + ≤3 tiny thumbnails) that jumps to Work.

## Scope (out)

- No media-upload backend changes (consumes existing media APIs).

## §0.10 pre-build checklist — all "yes"

- Goal visible in 5s? ✅ photos + voice — the instruction packet — are the whole tab.
- One dominant action? ✅ capture affordances (Add / Record) grouped per sub-section, not competing.
- Rare actions hidden? ✅ delete behind long-press + confirm.
- Related grouped? ✅ one Work Instructions card.
- Readable without editing? ✅ media is viewable; capture is opt-in.
- Colors only for meaning? ✅ accent = interactive, neutral grey otherwise.
- Status without calculating? ✅ voice age + upload spinners/retry shown.
- Destructive separated? ✅ delete is long-press + confirm.

## Implementation notes

- New `WorkTab.tsx` (the card) + `OverviewWorkCard.tsx` (the compact preview).
- `PhotoSection`/`VoiceSection` gained a **boring** `embedded?: boolean` prop — only margins and
  the standalone header change; capture/upload/playback logic is untouched (no second code path).
- "Notes" photo bucket relabeled **Measurement Notes** (matches the screen spec).
- Overview preview is read-only and re-fetches the media APIs; duplicate reads are acceptable for
  now and may later be consolidated with Work-tab data — deliberately not shared in 28.2.

## Deferred polish (review-noted)

- **Measurement Notes empty add-tile feels oversized in the 460px desktop drawer** (P3, not a bug).
  The grouping is correct; the tile could be capped/denser so the Work card reads more like a
  compact instruction packet. Candidate for 28.x density polish.

## Done when

The Work tab presents photos + measurement notes + voice as one coherent Work Instructions card;
Overview shows a compact work preview.
