# VS-28.2 — Work Tab (Work Instructions card)

**Program:** [VS-28 overview](./00-overview.md) · **Layer:** Frontend · **Status:** Pending

> **Frontend Design Gate:** read `07-ux-guidelines.md §0` and run §0.10 before editing this UI.

Merge garment photos, measurement/diary photos, and voice notes into one **"Work Instructions"**
card on the Work tab — the way a tailor thinks ("what do I need to make this order correctly?").

## Scope (in)

- Combine `PhotoSection` (garment + notes buckets) and `VoiceSection` (record + playback) into a
  single grouped card.
- An Overview "Today's Work" preview (garment / notes / voice thumbnails) that jumps to the Work tab.

## Scope (out)

- No media-upload backend changes (consumes existing media APIs).

## Done when

The Work tab presents photos + notes + voice as one coherent work card; Overview shows a compact
work preview.
